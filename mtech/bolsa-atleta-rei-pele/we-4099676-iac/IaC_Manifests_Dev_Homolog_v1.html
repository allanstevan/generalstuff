1. Descrição da tarefa

Usar IA para gerar os manifests de infraestrutura como código (ambientes dev/homolog) a partir do plano de segurança da Fase 1, com revisão humana e publicação versionada.

2. Princípios de segurança aplicados nos manifests

  • Segredos fora da imagem (env / secret store); nunca commit de credencial.
  • Rede interna entre serviços; exposição mínima de portas.
  • TLS na borda (ingress/túnel); cookies Secure em HML quando HTTPS.
  • Imagens pinadas por digest quando possível; scan (Trivy) no pipeline (#8312452).
  • Usuário não-root nos containers de app.
  • Separação física/lógica DEV ≠ HML (projetos/namespaces/redes distintas).
  • Backup e volume nomeado só onde necessário (Postgres); política de retenção a calibrar com a SEME.

3. Topologia alvo (dev / homolog)

Internet → Ingress/Túnel TLS
         → edge (proxy)
         → web (Next.js / PWA)
         → api (microsserviços / BFF)
         → postgres
         → (opcional) redis / filas
         → storage S3-compat ou volume (docs)

Stack de referência da arquitetura: PostgreSQL; front Next.js; containers Docker; portabilidade PRODAM.
